# ESP32 智能控制项目集

> 基于 ESP32 的智能硬件设计项目集合

---

## 项目简介

本仓库包含多个基于 ESP32 微控制器的智能硬件设计项目，涵盖电源管理、传感器监测、显示驱动等多个应用领域。每个项目都提供完整的原理图、PCB 设计、物料清单（BOM）和实物展示。

## 硬件设计规范

### 设计标准
- **PCB 层数**: 4 层设计
- **板材材质**: FR-4 玻纤（阻燃等级）
- **板厚度**: 1.6mm
- **最小线宽/线距**: 8mil

### 核心器件
- **微控制器**: ESP32 系列（双核 240MHz）
- **电源管理**: AMS1117-3.3 稳压芯片
- **通信模块**: WiFi 802.11 b/g/n + 蓝牙 4.2/5.0
- **工作电压**: 3.3V
- **输入电压**: 5V USB 或 3.3V 直接供电

## 开发环境

### 推荐工具
- **Arduino IDE**: 适合初学者，简单易用
- **PlatformIO**: 功能完整，支持多种开发板
- **ESP-IDF**: 官方工具，功能最全

### 常用库
- `TFT_eSPI`: IPS 屏幕驱动
- `DHT`: 温湿度传感器
- `PubSubClient`: MQTT 客户端
- `ArduinoJson`: JSON 数据处理
- `GxEPD2`: 墨水屏驱动

## 使用指南

### 硬件制作流程
1. 查看项目的物料清单（BOM）
2. 准备相应的元器件和材料
3. 参考 PCB 设计文件制作或购买 PCB
4. 按照原理图焊接元器件
5. 使用 Arduino IDE 或 PlatformIO 烧写固件
6. 测试验证功能

### 固件烧写步骤
1. 安装 ESP32 开发板支持包
2. 连接 ESP32 到电脑（USB 线）
3. 安装必要的依赖库
4. 打开固件代码文件
5. 配置 WiFi 和服务器参数
6. 选择开发板型号和串口
7. 编译并上传程序

### 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|--------|
| 无法识别设备 | USB 驱动未安装 | 安装 CH340 或 CP2102 驱动 |
| 烧写失败 | 无法进入烧写模式 | 长按 BOOT，再按 RST |
| 串口无输出 | 波特率设置错误 | 检查波特率是否为 115200 |
| WiFi 连接失败 | SSID 或密码错误 | 检查网络名和密码 |
